# Genebov

App de Genebov – Genética Bovina: cartera, inventario y catálogo de toros.

Aquí vive solo la pantalla. Los datos están en el archivo de Google Sheets
**EMPRESA GENEBOV**, detrás de un script de Apps Script protegido con PIN.

| Archivo | Qué es |
|---|---|
| `index.html` | Toda la app |
| `config.js` | La dirección del script de Apps Script |
| `manifest.json`, `iconos/`, `logo.png` | Para que se instale con icono propio |
| `sw.js` | Deja que la app abra sin internet |
| `.nojekyll` | Para que GitHub Pages publique los archivos tal cual |

Instrucciones completas de instalación: ver `INSTALAR.md` del paquete.
